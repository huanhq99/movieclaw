## movieclaw v0.17.1

这一版修复「设置 → 网络与代理」里通知服务的连通性测试误报。Telegram 通道本身已经能够
正常收发时，页面不再因为后端缺少探测目标而显示「不通」。

> 本版**不需要更新 Docker 运行时**（runtime 仍为 8）；新版镜像会随 Release 一并发布。

### 修复

- **Telegram / Discord 连通性测试**：分别使用无需凭证、不会产生消息的公开端点做真实探测，
  并继续复用各自业务客户端的代理服务标签。代理配置正确时会显示实际延迟和明确的连通结果。
- **Webhook 测试入口**：Webhook 的目标地址由用户逐条配置，网络页不再拿不存在的统一目标做
  测试；请在「设置 → Webhook」中对具体端点发送测试，结论会反映该端点的真实直连/代理配置。
- **内置服务测试能力同步**：后端服务目录明确声明服务是否支持固定目标探测，避免前端再次出现
  「有测试按钮、后端却不认识该服务」的错位。
