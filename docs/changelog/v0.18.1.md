## movieclaw v0.18.1

这是 `v0.18.0` 播放器与转码大更新之后的补丁版，重点修复通知服务的代理连通性测试回归。

### 修复

- **恢复 Telegram / Discord 的代理连通性测试**：测试现在访问各自无需鉴权的公开接口，按实际服务标签走代理，能区分线路不通与服务返回的 HTTP 状态。
- **Webhook 测试提示更准确**：Webhook 没有统一公网目标，网络设置页不再提供会误导用户的全局测试按钮，改为提示到 Webhook 设置对具体端点测试。
- **收口已忽略入库条目的遗留作业**：忽略条目后不再继续留下待处理的入库任务。

本版没有变更运行时依赖，`docker/runtime-version` 仍为 `9`。Docker 用户可更新到 `huanhq99/movieclaw:v0.18.1`（或 `:latest`），无需额外升级 runtime 契约。
