## movieclaw v0.18.2

本版同步上游最新修复，并保留 `v0.18.1` 的通知代理连通性修复。

### 新功能与改进

- **gpt-oss Harmony 格式残留检测**：当推理后端把 Harmony 特殊标记泄漏到正文或工具调用时，日志和会话会给出中文诊断，提示检查 vLLM、Ollama 或 llama.cpp 的解析器与 chat template 配置。
- **任务中心显示 Remux 规格**：任务中心的媒体规格行现在明确标注 Remux，便于区分下载质量。

本版没有变更运行时依赖，`docker/runtime-version` 仍为 `9`。Docker 用户可更新到 `huanhq99/movieclaw:v0.18.2`（或 `:latest`）。
